## Layout Contract

### Primary Screen: 仿真沙盒主界面

```
┌─────────────────────────────────────────────────────────┐
│ ┌─────────────────────────────────────────────────────┐ │
│ │  工具栏 (Toolbar)                                    │ │
│ │  ▶ 播放  ⏸ 暂停  ↺ 重置    帧率: 120fps  物体: 5   │ │
│ └─────────────────────────────────────────────────────┘ │
│                                                           │
│                                                           │
│                   3D 视口 (Viewport)                       │
│              Three.js + R3F 全窗口画布                    │
│                                                           │
│              ┌──┐                                         │
│              │  │ ← 方块                                  │
│              └──┘                                         │
│            ●  ← 球体                                      │
│         ╱¯¯¯╲                                             │
│        ╱     ╲  ← 斜面                                   │
│       ╱       ╲                                           │
│      ¯¯¯¯¯¯¯¯¯¯                                           │
│                                                           │
│        鼠标拖拽=旋转 | 滚轮=缩放 | 右键=平移              │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

**Focal point**: 3D 视口是主视觉锚点，占据 >95% 屏幕空间。工具栏浮动在视口上方，半透明不遮挡场景。

**视觉层级**:
1. 3D 场景中的物理物体（主焦点）
2. 工具栏控制按钮（次要交互）
3. 状态指示器（帧率、物体计数）

## Color

Dark theme — physics sandbox standard:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0a0a0a` | 3D 视口背景、页面底色 |
| Secondary (30%) | `#1a1a1a` | 工具栏背景、按钮底色 |
| Accent (10%) | `#3b82f6` (blue-500) | 播放按钮激活态、焦点环 |
| Destructive | `#ef4444` (red-500) | 重置按钮悬停态 |

**Accent reserved for:**
- 播放/暂停按钮的激活/运行状态指示
- 输入焦点环 (focus ring)
- （后续 Phase 可扩展：选中物体高亮）

**Destructive reserved for:**
- 重置按钮 hover/focus 状态
- （后续 Phase 可扩展：删除物体确认）

## Interaction States

### 播放按钮

| 状态 | 外观 | 行为 |
|------|------|------|
| 就绪 (仿真未开始) | ▶ 播放 — slate 底色，蓝色图标 | 点击启动仿真 |
| 运行中 | ⏸ 暂停 — 蓝色底色（accent），白色图标 | 点击暂停仿真 |
| 已暂停 | ▶ 继续 — slate 底色，蓝色图标 | 点击继续仿真 |

### 重置按钮

| 状态 | 外观 | 行为 |
|------|------|------|
| 默认 | ↺ 重置 — slate 底色，灰色图标 | 点击恢复初始场景 |
| Hover | ↺ 重置 — red-500 底色，白色图标 | 视觉警示 |

### 工具栏

| 状态 | 外观 |
|------|------|
| 默认 | 半透明背景 `rgba(26, 26, 26, 0.85)`，`backdrop-filter: blur(8px)` |
| 鼠标悬停 | 增加不透明度至 `0.95`，浮现于视口之上 |

### 3D 视口

| 状态 | 外观 |
|------|------|
| 默认 | 深色背景 `#0a0a0a`，渲染坐标网格辅助线（可选） |
| 加载中 | 中央显示加载指示器（旋转圆环），文字"加载物理引擎..." |
| 错误 | 中央显示错误卡片（错误图标 + 标题 + 描述 + 操作建议） |

## Accessibility

- 所有按钮提供 `aria-label`（中文）：`aria-label="播放仿真"`、`aria-label="暂停仿真"`、`aria-label="重置仿真"`
- 键盘快捷键：`Space` = 播放/暂停切换，`R` = 重置
- 快捷键通过 Tooltip 提示
- OrbitControls 提供键盘替代操作（方向键旋转）
- 颜色对比度符合 WCAG AA 标准
