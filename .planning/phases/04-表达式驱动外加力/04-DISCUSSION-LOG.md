# Phase 4 讨论日志

## 概述

本次讨论聚焦 Phase 4（表达式驱动外加力）的三个实现决策领域。所有决策已锁定并写入 `04-CONTEXT.md`。

---

## 领域 1：表达式输入界面

### 问题 1：表达式力输入放在哪里？
- **选项：** PropertyPanel 内联 / 独立表达式对话框 / 两者结合
- **选择：** 独立表达式对话框
- **理由：** 空间充裕，可放完整辅助信息；PropertyPanel 保持紧凑

### 问题 2：是否需要实时预览当前值？
- **选项：** 需要实时预览 / 不需要
- **选择：** 需要实时预览
- **理由：** 帮助用户确认公式效果，降低调试成本

### 问题 3：对话框里除了输入框还应放什么？
- **选项：** 基础版（仅输入框+错误+预览）/ 完整版（+速查表）/ 完整版+示例
- **选择：** 完整版（变量速查表 + 函数速查表 + 实时预览 + 错误提示）
- **理由：** 对高中生用户友好，降低记忆负担

### 问题 4：输入是单行还是多行？
- **选项：** 单行输入 / 多行 textarea
- **选择：** 单行输入（每分量一行）
- **理由：** 更紧凑；不支持条件表达式语法（超出需求范围）

---

## 领域 2：表达式辅助功能

### 问题 1：是否提供预设表达式快捷插入？
- **选项：** 提供物理公式预设 / 只提供空输入框
- **选择：** 只提供空输入框
- **理由：** 坚持 Physis "自由组合" 核心理念，不预设任何模板。与 v1.0 废案教训一致。

### 问题 2：除了速查表还有什么辅助功能？
- **选项：** 纯文本速查表 / 速查表+点击插入 / 以上+语法高亮
- **选择：** 以上+语法高亮
- **理由：** 提升可读性和输入效率

### 问题 3：是否需要迷你矢量图？
- **选项：** 需要迷你矢量图 / 不需要
- **选择：** 需要迷你矢量图
- **理由：** 用箭头直观展示力的方向和大小，帮助用户理解公式

### 问题 4：PropertyPanel 中如何显示已绑定的表达式？
- **选项：** 只显示开关和简短摘要 / 显示完整只读输入框
- **选择：** 只显示开关和简短摘要（如 "fx: sin(t)"）
- **理由：** 紧凑，与 PropertyPanel 现有布局风格一致

---

## 领域 3：运行时错误行为

### 问题 1：语法错误的处理方式？
- **选项：** 红框禁用 / 红框+提示 / 实时阻止输入
- **选择：** 红框禁用
- **理由：** 最安全策略，避免无效表达式进入仿真

### 问题 2：运行时错误的处理方式？
- **选项：** 零力回退 / 表达式暂停 / 最近有效值
- **选择：** 表达式暂停
- **理由：** 最安全策略，明确告知用户公式有问题，而不是静默忽略或卡死在旧值

### 问题 3：错误警告如何展示？
- **选项：** 红色图标+悬停详情 / 对话框直接弹出 / 两者都用
- **选择：** 红色警告图标+悬停显示错误详情
- **理由：** 不打断用户操作，信息密度适中

### 问题 4：表达式力与力场是否可以叠加？
- **选项：** 完全叠加 / 互斥开关
- **选择：** 完全叠加（表达式+力场+重力）
- **理由：** 物理正确，实验自由度最大
