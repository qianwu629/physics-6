**导出函数（非 React 组件）：**

1. **`exportSceneToFile(): void`** — D-01-01 + D-01-04 导出功能：
   ```
   1. const state = useSimulationStore.getState()
   2. const sceneData = serializeScene({ entities: state.entities, environment: state.environment })
   3. const jsonString = JSON.stringify(sceneData, null, 2)
   4. const blob = new Blob([jsonString], { type: 'application/json' })
   5. const url = URL.createObjectURL(blob)
   6. const timestamp = new Date().toISOString().replace(/[:.]/g, '-')
   7. const filename = `physis-scene-${timestamp}.json`
   8. const a = document.createElement('a'); a.href = url; a.download = filename
   9. document.body.appendChild(a); a.click(); document.body.removeChild(a)
   10. URL.revokeObjectURL(url)
   ```
   - 文件名格式：`physis-scene-{YYYY-MM-DDTHH-mm-ss-SSSZ}.json`（ISO 8601 中的 `:` `.` 替换为 `-`）
   - 不检查 entities.size === 0（允许导出空场景）

2. **`importSceneFromFile(file: File): Promise<{ success: boolean; data?: { entities: Map<string, Entity>; environment: EnvironmentState }; warnings: string[]; errors: string[] }>`** — D-01-08 导入处理：
   ```
   1. 文件大小 > 5MB 时 reject (D-01-08: Modal 拒绝)
   2. new FileReader().readAsText(file)
   3. onload: JSON.parse(result) 包裹 try/catch
   4. 解析成功 → 调用 deserializeScene(json)
   5. 返回结构化结果 { success, data?, warnings, errors }
   6. onerror/parse error → 返回 { success: false, errors: ['...'] }
   ```

3. **`loadSceneWithConfirm(sceneData: { entities: Map<string, Entity>; environment: EnvironmentState }): Promise<boolean>`** — D-01-03 加载流程：
   ```
   1. 调用 showConfirmDialog() → 等待用户确认（返回 Promise<boolean>）
   2. 取消 → return false
   3. 确认后顺序执行:
      a. useSimulationStore.getState().pause()          // 强制暂停
      b. useSimulationStore.getState().resetEntities()  // 清空现有实体
      c. useSimulationStore.getState().reset()          // 递增 resetCounter（触发 Physics 重挂载+相机重置+轨迹清空）
      d. 加载环境参数:
         const store = useSimulationStore.getState()
         store.setGravity(sceneData.environment.gravity)
         store.setFrictionScale(sceneData.environment.frictionScale)
         store.setRestitutionScale(sceneData.environment.restitutionScale)
         store.setDrag(sceneData.environment.drag)
      e. 遍历 sceneData.entities，逐个调用:
         store.addEntity(entity)  // 使用 store 的不可变更新
         对于 constraint entity，在 addEntity 前检查 entityAId/entityBId 是否存在于已添加的 entities 中
         如果引用失效（目标实体不存在），跳过该约束并记录 warning (D-01-08)
      f. 摄像机自适应由 Scene3D 的 useEffect([resetCounter]) 自动处理（Plan 05 实现）
   4. return true
   ```

4. **`showConfirmDialog(message: string): Promise<boolean>`** — 确认对话框帮助函数：
   - 利用浏览器原生 `confirm()` 作为 fallback（简洁方案）
   - 或创建 React 组件（`<ConfirmDialog>`）——推荐创建轻量 React 组件，以保持 UI 风格一致
   - 使用 `Dialog` + `DialogContent` + `DialogHeader` + `DialogFooter`
   - Props: `{ open: boolean; message: string; onConfirm: () => void; onCancel: () => void }`
   - 返回 Promise，在 onConfirm 中 resolve(true)，onCancel 中 resolve(false)
