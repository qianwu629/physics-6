```typescript
// ── Phase 5: Rapier 运行时属性同步 (REN-03 / Pitfall 5 闭环) ──
// 根因：@react-three/rapier 把 mass/restitution/friction/damping 视为初始化 props；
//      挂载后必须通过 imperative API 同步。restitution / friction 是 collider-level。
useEffect(() => {
  const rb = rigidBodyRef.current;
  if (!rb) return;

  // RigidBody-level
  rb.setAdditionalMass(rigidBody.mass, true);
  rb.setLinearDamping(drag);
  // 部分版本暴露 setAngularDamping；若类型不存在用 any 兜底
  if (typeof (rb as any).setAngularDamping === 'function') {
    (rb as any).setAngularDamping(drag * 0.5);
  }

  // Collider-level（restitution / friction 在 Rapier 中是 collider 属性）
  if (typeof rb.numColliders === 'function' && rb.numColliders() > 0) {
    const col = rb.collider(0);
    col.setRestitution(Math.min(rigidBody.restitution * restitutionScale, 1.0));
    col.setFriction(Math.min(rigidBody.friction * frictionScale, 2.0));
  }
}, [
  rigidBody.mass,
  rigidBody.restitution,
  rigidBody.friction,
  restitutionScale,
  frictionScale,
  drag,
]);
```

实现细节与约束:
- **不要删除** RigidBody 上的现有 mass/restitution/friction/linearDamping props；它们对首次挂载的初始化仍然必需。useEffect 只负责挂载后的更新。
- 使用 `rb.setAdditionalMass(mass, true)` 而非 `setMassProperties`：D-01 决策选择 setAdditionalMass（最小侵入；不需要重新计算 inertia tensor）。
- restitution / friction 必须走 `rb.collider(0)`，因为 Rapier3D 中这两个值物理上属于 Collider，不在 RigidBody 上。直接调用 `rb.setRestitution` 在类型上不存在。
- `setAngularDamping` 在某些 Rapier 版本类型未导出但实际运行时存在；用 `(rb as any).setAngularDamping` 兜底（Claude 自由裁量项）。如果类型完整定义就直接调用。
- 依赖数组**严格**只包含会影响 Rapier 状态的字段，**不**包含 transform.position / velocity（这些是另一个话题——见 out-of-scope 注释，在 useEffect 上方添加注释说明）。
- 使用 `Math.min(... * scale, 1.0/2.0)` 公式与第 136-137 行 prop 保持一致。
- 在文件顶部不需要新导入；`useEffect` 已从第 1 行 import。
- 在 useEffect 上方添加注释：`// 注意：position/velocity 的运行时同步未在此 useEffect 处理（暂停态编辑可走 reset 链路；运行时编辑会被物理积分覆盖，不是有意义的语义）。`
