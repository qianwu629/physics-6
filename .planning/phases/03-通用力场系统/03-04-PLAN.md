  <action>
    1. 创建 `frontend/src/components/ForceFieldRenderer.tsx`：
       - 从 `useSimulationStore((s) => s.entities)` 读取所有力场实体
       - 对每种 kind 分别渲染：
         - **uniform / magnetic**：
           - 在 range 范围内按 2m 间距生成网格点（x/z 平面，y 可多层或单层）
           - 使用 `InstancedMesh` 批量渲染箭头
           - 箭头 = ConeGeometry（头部）+ CylinderGeometry（杆部）组合，或用单个 Cone 简化
           - 方向 = field.direction（uniform）或 field.direction（magnetic），归一化后旋转
           - 颜色：uniform = #3b82f6（蓝），magnetic = #a855f7（紫）
           - 长度固定（如 0.8m），不随强度变化（均匀场强度处处相等）
         - **gravity / electric**：
           - `SphereGeometry` + 自定义 `ShaderMaterial`（实现径向透明度衰减 D-03-07）
           - radius = field.range
           - 顶点着色器：标准 projection * modelViewMatrix * position
           - 片段着色器：
             - 计算 `dist = length(vPosition - sphereCenter)`（通过 worldPosition 或 uniform 传入中心）
             - `alpha = 0.35 * (1.0 - smoothstep(0.0, 1.0, dist / radius))` — 中心 opacity≈0.35，边缘 opacity→0
             - `gl_FragColor = vec4(color, alpha)`
           - uniforms: `{ color: { value: new THREE.Color(...) } }, { radius: { value: field.range } }, { center: { value: new THREE.Vector3(...) } }`
           - transparent: true, depthWrite: false, side: THREE.DoubleSide
           - 颜色：gravity = #88aabb（淡蓝灰）
           - electric：field.charge > 0 → #ff4444（红），field.charge < 0 → #4444ff（蓝），field.charge === 0 → #888888
           - 中心点可加小发光球（SphereGeometry + emissive 材质）标识源位置
       - 使用 `useMemo` 缓存几何体和材质，避免每帧重建
       - 使用 `useFrame` 仅在实体变化时更新 InstancedMesh 的矩阵（或直接用 React 声明式渲染如果数量少）
       - 数量预估：range=10m → 网格点约 5x5x5=125 个，InstancedMesh 1 个 draw call 足够
    2. 导出 `ForceFieldRenderer` 默认组件。
  </action>
