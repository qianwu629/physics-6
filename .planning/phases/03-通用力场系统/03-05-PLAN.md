       - 按 kind 生成力线几何：
         - **uniform**：平行等距直线，在 range 范围内按 2m 间距排列，方向 = field.direction

         - **magnetic**：均匀磁场用平行线（同 uniform）；若未来支持非均匀磁场可扩展
       - 使用 `LineSegments` + `BufferGeometry` 渲染
       - 颜色与 ForceFieldRenderer 一致（uniform 蓝、gravity 淡蓝灰、electric 红/蓝、magnetic 紫）
       - 静态几何：用 `useMemo` 仅在力场实体变化时重建
    4. 在 Scene3D.tsx 挂载 `<ForceFieldLines />`（Physics 外部）。
