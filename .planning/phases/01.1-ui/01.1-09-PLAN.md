**A) index.css — prefers-reduced-motion 媒体查询 (L-09 缓解)**

在 index.css 末尾添加：

```css
/* === Phase 01.1: prefers-reduced-motion (UI-06 a11y) === */
/* 仅作用于 UI 动画层 — 物理模拟 useFrame / Canvas 重绘不受影响 (OQ-5) */
@media (prefers-reduced-motion: reduce) {
  /* UI 面板动画 */
  [data-ui-animate] *,
  .transition-all,
  .transition-colors,
  .transition-opacity,
  .transition-transform,
  .duration-150,
  .duration-200,
  .duration-300 {
    transition-duration: 0ms !important;
    animation-duration: 0ms !important;
  }
}
```

注意：scope 限定在 `[data-ui-animate] *` 和具体的 transition 类上。不使用 `*` 全局选择器避免误伤 Canvas 的 Three.js 动画。如果 WorkspaceLayout 或其他 UI 容器添加 `data-ui-animate` 属性，则其子元素受 reduced-motion 约束。

（OQ-5 决议: 物理模拟 useFrame 不节流——仅 UI 动画受限。此 CSS 规则仅覆盖 transition/animation 类，不影响 Three.js 内部的 requestAnimationFrame 渲染循环。）
