# Phase 01.1 — UI/UX Pro Max 框架（plan-phase 输入）

## P1 · CRITICAL — Accessibility & Touch

| 编号 | 约束 | 验证 |
|------|------|------|
| P1-A1 | 触控目标 ≥ 44×44px — 图标按钮统一 `w-11 h-11` | `rg "w-10 h-10" frontend/src/components` 出现即 FAIL |
| P1-A2 | 文字对比 dark+light 双主题 ≥4.5:1 | 取色 + WCAG 计算 |
| P1-A3 | icon-only `<button>` 必须 `aria-label` | `rg "<button(?![^>]*aria-label)" --pcre2 -t tsx` |
| P1-A4 | Toggle 按钮须 `aria-pressed={state}` | grep 核对 |
| P1-A5 | `:focus-visible` 显示 `ring-2 ring-ring ring-offset-2` | shadcn 默认，不可覆盖 |
| P1-A6 | Tab 顺序：MenuBar → Toolbox → Canvas → Inspector Tabs → 内容 → Toolbar | 手动走查 |

## P2 · HIGH — Layout / Token / Z-Index

| 编号 | 约束 | 验证 |
|------|------|------|
| P2-L1 | 删除 `App.tsx` 中 `[data-toolbar] { top: 44px !important }` | grep 0 命中 |
| P2-L2 | 顶层 grid 固定 `grid-cols-[var(--sidebar-width)_1fr_var(--inspector-width)] grid-rows-[var(--menubar-height)_1fr_var(--toolbar-height)]` | grep 命中 |
| P2-T1 | 禁止硬编码 `rgba(` / `#xxxxxx` / `backdrop-blur(8px)` 在 component 文件 | grep 0 命中 |
| P2-T2 | 颜色一律 `hsl(var(--<token>))` 或 Tailwind class | grep 核对 |
| P2-Z1 | z-index 一律 `z-[var(--z-<role>)]`，禁止 `z-40/z-50` 数字 | grep `z-[0-9]` 0 命中 |
| P2-Z2 | `:root` 含完整 `--z-base/canvas/panel/overlay/menu/dialog/toast` 7 个变量 | `wc -l` ≥ 7 |
| P2-A1 | Accent 仅用于白名单 6 项 | code review |

## P3 · MEDIUM — Performance / Animation / Style

| 编号 | 约束 |
|------|------|
| P3-M1 | `prefers-reduced-motion` → UI 动画 0ms；物理 useFrame 不节流 |
| P3-M2 | 微交互 `transition-colors duration-200` (150-300ms) |
| P3-M3 | hover 禁止 `scale` transform |
| P3-S1 | 字号 3 档 + 字重 2 档；禁止 `text-lg/xl/2xl` 与 `font-medium/bold` |
| P3-S2 | Mono 字体仅用于 FPS/坐标/时间 |
| P3-S3 | 不用 emoji 当 icon |
| P3-C1 | Light 下浮层背景至少 `bg-card/90` |

## 实施路径（Token-first）

1. **Wave 1 — Foundation**：shadcn 组件安装 + index.css token 完善 + ThemeProvider + ThemeToggle
2. **Wave 2 — Skeleton**：WorkspaceLayout grid + Inspector Tabs + Toolbox 左列 + Toolbar 底部
3. **Wave 3 — Bug Fix + Token Migration**：C-02/W-02/C-03/W-01/HACK-02 修复 + 全量 token codemod
4. **Wave 4 — Responsive + 预留**：3 断点 + Phase 3/5 入口 + a11y 扫尾

## 风险 Landmines（12 条）

| ID | Landmine | 缓解 |
|----|----------|------|
| L-01 | `z-[var(--z-panel)]` 被 Tailwind purge | safelist 或 `@source inline(...)` |

| L-03 | ThemeProvider 切换致 R3F Canvas 重新挂载 | React.memo(Scene3D) |
| L-04 | Sheet modality 与 Slider drag 冲突 | `modal={false}` |
| L-05 | W-01 上限检查忽略已启用实体 | useChartEnabledCount selector |
| L-06 | 删 CSS 注入后 Toolbar 位置没改 | acceptance_criteria grep |
| L-07 | Light 下 ChartPanel 浮层看不清 | border 必须可见 |
| L-08 | Tabs underline 色与 accent 白名单冲突 | 改为 `border-primary` |
| L-09 | reduced-motion 全局 `*` 选择器误伤 Canvas | scope 限定 |
| L-10 | disabled button + tooltip keyboard 不可达 | `aria-disabled` + focusable |
| L-11 | md: 断点 Toolbar 按钮挤压 | 显式 hidden 标注 |
| L-12 | codemod 误伤 ChartPanel 业务颜色 | dry-run + diff |
