## 2. Spacing Scale

8 点对齐基准。**全部值必须为 4 的倍数**。Tailwind v4 默认尺度（`gap-1 gap-2 gap-4 gap-6 gap-8`）即对应。

| Token | 值 | Tailwind 类 | 用途（Phase 01.1 上下文） |
|-------|-----|-------------|-------------------------|
| xs | 4px | `gap-1 / p-1` | Icon 与文字间距、Badge 内边距 |
| sm | 8px | `gap-2 / p-2` | Toolbar 按钮组、Tab Trigger 间距、Form Row 内紧凑间距 |
| md | 16px | `gap-4 / p-4` | Inspector Tab 内容内边距、Toolbox 列表项间距、Dialog 内容默认 |
| lg | 24px | `gap-6 / p-6` | Drawer Section 间隔、Dialog Header/Footer 上下间距 |
| xl | 32px | `gap-8 / p-8` | Dialog 主体外边距、Empty State 内边距 |
| 2xl | 48px | `gap-12` | 仅用于 Empty State 图标与文案间距 |

### Layout Skeleton 固定尺寸

| 元素 | 尺寸 | CSS 变量 |
|------|------|----------|
| MenuBar 高度 | 36px (`h-9`) | `--menubar-height: 2.25rem` |
| Toolbar（底部状态条）高度 | 40px (`h-10`) | `--toolbar-height: 2.5rem` |
| 左列 Toolbox 宽度 | 220px | `--sidebar-width: 13.75rem` |
| 右列 Inspector Drawer 宽度 | 320px | `--inspector-width: 20rem` |
| 触控目标最小尺寸 | **44×44px** (`w-11 h-11`) | a11y P1 强制 |

### 例外说明

- ChartPanel 浮动模式默认尺寸 `w-[480px] h-[320px]`（4 的倍数 ✓），最小 `w-[320px] h-[200px]`
- shadcn `--radius` 保留默认 `0.625rem`（10px，作为视觉圆角而非间距，不计入 spacing scale）

## 3. Typography

3 个字号 + 2 个字重，符合 P1 强约束。

| Role | 字号 | Tailwind 类 | 字重 | Line-height | 用途 |
|------|------|-------------|------|-------------|------|
| Caption | 12px | `text-xs` | 400 (regular) | 1.5 (`leading-normal`) | FPS / 对象数 / 时间戳 / 单位标注 |
| Body | 14px | `text-sm` | 400 (regular) | 1.5 (`leading-normal`) | PropertyPanel 字段值、按钮 label、说明文字、Tab 标题 |
| Heading | 16px | `text-base` | 600 (semibold) | 1.2 (`leading-tight`) | Dialog Title、Drawer Section Header、菜单组标题 |

> **不引入额外字号**。Display（24px+）在本 Phase 不需要——栅格化工作台没有大标题区域。
> **字重严格 2 选 1**：400 与 600，禁止 300 / 500 / 700。Geist Variable 已在 `index.css` 限定为 `wght@400;600`。

### Mono 字体使用约束

`font-mono`（Geist Mono）仅用于：FPS 数字、坐标 (x, y, z)、时间秒数。其余一律 sans。

## 4. Color

60 / 30 / 10 严格执行；accent 受限白名单。

### 主题底色（已在 `frontend/src/index.css` 定义，本 Phase 维持）

| Role | Dark 主题 (oklch) | Light 主题 (oklch) | 用途 |
|------|-------------------|-------------------|------|
| **Dominant 60%** `--background` | `oklch(0.145 0 0)` ≈ `#252525` | `oklch(1 0 0)` = `#ffffff` | App 主背景、Canvas 容器底色 |
| **Secondary 30%** `--card` / `--sidebar` | `oklch(0.205 0 0)` | `oklch(1 0 0)` | Toolbox 左列、Inspector Drawer、Toolbar、MenuBar、Dialog 容器 |
| **Accent 10%** `--primary` (dark) / `--ring` | dark: `oklch(0.922 0 0)`（亮灰） | light: `oklch(0.205 0 0)`（深灰） | **见下方白名单** |
| **Destructive** `--destructive` | `oklch(0.704 0.191 22.216)` (红) | `oklch(0.577 0.245 27.325)` | 删除实体、清空快照、覆盖加载等仅破坏性操作 |
| **Muted FG** `--muted-foreground` | `oklch(0.708 0 0)` | `oklch(0.556 0 0)` | 次要文字、单位、占位符 |
| **Border** `--border` | `oklch(1 0 0 / 10%)` | `oklch(0.922 0 0)` | 所有面板边框、分隔线 |

### Accent 白名单（10% 严格保留范围）

`--primary` / `--ring` **只能**出现在以下元素：

1. Toolbar 「播放/暂停」主按钮（运行态高亮）
2. Inspector Drawer 当前激活 Tab 的下划线
3. 表单输入框 focus 环 (`ring-2 ring-ring`)
4. 选中实体在 EntityList 中的高亮项
5. ChartPanel 中"当前选中实体曲线"高亮色（仅 1 条，其余按 `--chart-1..5` 色阶）
6. PresetSelector 当前 hover/selected 卡片描边

> **禁止**用于：所有次要按钮、Switch 默认态、Slider 轨道、Tab Trigger 默认态、Empty State 图标、Section Header 文字。

### 对比度合同（D-01.1-09 强约束）

| 文字层 | 对比度 | 验证基准 |
|--------|--------|----------|
| `foreground` on `background` | ≥ 7:1 | WCAG AAA |
| `foreground` on `card` | ≥ 7:1 | WCAG AAA |
| `muted-foreground` on `card` | ≥ **4.5:1** | WCAG AA（强制下限） |
| `primary-foreground` on `primary` | ≥ 4.5:1 | WCAG AA |
| `destructive-foreground` on `destructive` | ≥ 4.5:1 | WCAG AA |

> Light 主题下 oklch 已计算对齐；checker 必须验证两个主题均通过。

### 3D Canvas 背景策略（OQ-4 解析）

R3F Canvas 背景**不跟随主题切换**，固定保留偏暗灰 `#1a1a20`（与 EntityRenderer 颜色对比保持一致），避免浅色主题下 3D 物体颜色失真。但 Canvas 容器边框、Grid 辅助线颜色跟主题切换。

## 5. Z-Index Scale (UI-07)

CSS 变量栈定义在 `:root`（dark/light 共用）：

```css
:root {
  --z-base:    0;   /* 普通文档流 */
  --z-canvas: 10;   /* 3D Canvas 容器 */
  --z-panel:  20;   /* Toolbox / Inspector Drawer / Toolbar / MenuBar */
  --z-overlay:30;   /* ChartPanel 浮动、SceneBanner、SpringCreationBanner */
  --z-menu:   40;   /* DropdownMenu / Tooltip popper */
  --z-dialog: 50;   /* Dialog / Sheet / AlertDialog */
  --z-toast:  60;   /* Sonner Toast（最高层） */
}
```

Tailwind 任意值用法：`z-[var(--z-panel)]`。**禁止**出现 `z-40` / `z-50` 等数字字面量。

## 7. Responsive Behavior (UI-05)

| 断点 | 宽度 | 列数 | 左 Toolbox | 右 Inspector | Toolbar |
|------|------|------|------------|--------------|---------|
| `xl` | ≥1280px | 3 | 固定 220px 内联 | 固定 320px 内联 | 完整（所有 toggle） |
| `md` | 1024-1279px | 2 + Sheet | 固定 220px 内联 | **shadcn Sheet 抽屉**（按钮唤出） | 精简（隐藏次要矢量 toggle） |
| `sm` | <1024px | 1 + 浮层 | DropdownMenu (FAB 触发，左下角) | Sheet 抽屉（手动唤出） | 极简（仅 Play/Pause/Reset/FPS） |

> 触控交互（虚拟摇杆/手势）**不在本 Phase**——延后 Phase 5。本 Phase 的 sm 断点仅做布局结构变化。

## 8. Accessibility Baseline (UI-06, D-01.1-09)

强制清单（ui-checker 必须验证）：

| 维度 | 规则 | 验证手段 |
|------|------|----------|
| 触控目标 | 所有可点击元素 ≥ **44×44px**（Toolbar/Toolbox 图标按钮统一 `w-11 h-11`） | grep `w-10 h-10` 出现即 FAIL |
| 文字对比 | `foreground/background` ≥ 7:1，`muted-foreground/background` ≥ 4.5:1（dark+light 双主题验证） | 手动取色 + 对比度计算工具 |
| Tab 导航 | 顺序：MenuBar → Toolbox → Canvas → Inspector Tabs → Inspector 内容 → Toolbar | 手动 Tab 走查 |
| `aria-label` | 所有 icon-only 按钮（Play/Pause/Reset/Toggle/Close/Drawer 唤起按钮）必须配 `aria-label="<动作描述>"` | grep `<button` 不含 `aria-label` 且无 child 文本即 FAIL |
| `aria-pressed` | Toggle 类按钮（矢量显示/轨迹/调试/摄像机模式/2D）必须 `aria-pressed={state}` | 同上 |
| `prefers-reduced-motion` | 所有 UI 动画（Drawer 滑入/Toast 淡出/Tab 切换）在 `@media (prefers-reduced-motion: reduce)` 下时长设 `0ms` | CSS audit |
| 焦点可见 | 所有 focusable 元素 `:focus-visible` 显示 `ring-2 ring-ring ring-offset-2` | 视觉走查 |
| 键盘陷阱 | Dialog/Sheet 打开后焦点锁定且 Esc 关闭 | shadcn 默认行为，executor 不能破坏 |

### `prefers-reduced-motion` 边界（OQ-5 解析）

- **节流**：所有 UI 动画（Tab 切换、Drawer 滑入、Toast 淡出、Tooltip 渐显）→ `transition-duration: 0ms`
- **不节流**：物理模拟 useFrame、轨迹绘制、矢量箭头、Canvas 重绘——这是科学内容而非装饰，节流会破坏教学
