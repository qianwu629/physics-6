# Phase 01.1 — UI 重构 · CONTEXT

## Goal

全面重构 Physis UI——修复现有浮层缺陷、建立统一 shadcn/ui 设计系统与双主题、将散乱浮层升级为 Blender 风格栅格化工作台、引入响应式断点骨架与 a11y 基线、为 Phase 3（力场）和 Phase 5（摄像机/2D）预留 UI 进入点。

## Requirements (本次讨论派生)

| ID | 需求 | 来源 |
|----|------|------|
| UI-01 | 修复 Phase 2 浮层缺陷：C-02(Draggable+Resizable ref 冲突)、C-03(分离模式渲染 bug)、W-01(4实体上限未强制)、W-02(re-resizable 句柄类名)，拆除 App.tsx CSS 注入 hack；修复 PropertyPanel 折叠态孤立浮按钮 | G-1(a) |

| UI-03 | 深/浅双主题支持，通过 next-themes 或等价方式驱动切换；MenuBar [视图] → 主题入口 | G-4(b) |

## Locked Decisions

| ID | 决策 | 理由 | 来源 |
|----|------|------|------|
| D-01.1-01 | Goal = 浮层修复 + 设计系统 + 栅格化 + Phase 3/5 前置 + a11y 基线（全部 4 项） | 用户原话仅"ui重构"信息极薄；本次 discuss 逐项落锤确认全面重构范围 | G-1 all |
| D-01.1-02 | 设计系统 = shadcn/ui theme provider + CSS variables | 项目已用 shadcn/ui 原子组件（dialog/sheet/slider/switch/dropdown-menu/tooltip），token 体系天然一致；自建 token 重复造轮 | G-2(b) |
| D-01.1-03 | 布局 = Blender 风格栅格化三栏（左 Toolbox + 中 Canvas + 右 Drawer + 底 Toolbar） | 浮层散乱 + CSS 注入 hack 证明当前模式已达架构极限；栅格化提供清晰空间契约，降低 z-index 冲突 | G-3(b) |
| D-01.1-04 | 主题 = 深/浅双主题 | 教学场景（投影仪/打印）需要浅色；shadcn/ui theme provider 天然支持 | G-4(b) |

| D-01.1-08 | Toolbar 从顶部浮层下沉到底部状态条（模拟控制 + FPS/对象数 + 图表开关 + 摄像机模式预留） | 栅格化后顶部为 MenuBar + Canvas 边距；底部条是 Blender/Unity 常见位置 | G-3(b) 派生 |
| D-01.1-09 | a11y 基线：44×44 触控 / 4.5:1 对比度 / Tab 顺序 / prefers-reduced-motion / aria-label 补全 | ui-ux-pro-max skill P1-P2 强制要求；高中生教学场景多设备/投影环境对 a11y 有实际需求 | G-1(b) |
| D-01.1-10 | Phase 2 数据层 bug（C-01/C-04/C-05/C-06/C-07）不属于 UI-01，进 Phase 02 review-fix | 它们是数据/内存层 bug，不是 UI 重构范畴 | scope guardrail |

## Scope Guardrails

### IN scope
- 修复 Phase 2 UI 层 bug：C-02 (ref 冲突)、C-03 (渲染)、W-01 (上限强制)、W-02 (句柄类名)
- 拆除 App.tsx CSS 注入 hack（[data-toolbar] top 重设）
- 修复 PropertyPanel 折叠态孤立浮按钮
- 建立 shadcn/ui CSS 变量完整体系
- 实现深/浅双主题切换
- 栅格化布局：左列 + 中央 + 右 Drawer + 底部 Toolbar
- 响应式 3 断点 CSS Grid + 媒体查询骨架
- a11y：触控目标 / 对比度 / Tab / reduced-motion / aria
- z-index 统一标度
- Phase 3 力场 UI 入口预留 + Phase 5 摄像机/2D 模式 Toggle 预留
- ChartPanel 浮动模式保留（在栅格化框架内作为自由层）
- MenuBar / SnapshotManager / PresetSelector / SceneBanner / CreationDialog / SpringCreationDialog — 保持功能不变，仅适配新 token + 新布局

### OUT of scope（进 Phase 02 review-fix）
- C-01: 时间基准 mismatch（ChartSampler performance.now() vs ChartCanvas Date.now()）→ 数据层
- C-04: peReferenceY 重复 → 图表计算 bug
- C-05: buffer 泄漏 → 内存管理 bug
- C-06: snapshot load 泄漏 → 生命周期 bug
- C-07: chart.update 数据缺口 → 图表计算 bug

### OUT of scope（进 deferred ideas）
- CSV 导出功能
- 时间操控（快进/慢放/倒放）
- 多场景对比模式
- 物理量具（量角器/直尺 overlay）
- 预制题目模板
- 移动端原生 App
- 多人协作

## Responsive Behavior

| 断点 | 布局 | 左列 | 右列 | Toolbar |
|------|------|------|------|---------|
| ≥1280px | 完整三栏 | 固定 220px | 固定 320px | 完整 |
| 1024-1279px | 双栏 + Drawer | 固定 220px | 缩为 Sheet Drawer | 精简 |
