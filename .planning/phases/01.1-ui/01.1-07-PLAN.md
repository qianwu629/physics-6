在 PropertyPanel.tsx 中为「图表追踪」Switch 添加上限检查逻辑。

**现状:** PropertyPanel 中有两处「图表追踪」Switch（常规实体编辑器 line 763-769 和弹簧编辑器 line 513-515），均无条件调用 `toggleTracking`。

**修改 A) 添加上限检查 selector**

在组件顶部（已有 `const trackedIds = useChartDataStore((s) => s.trackedEntityIds)` 之后）追加：

```typescript
const MAX_CHART_ENTITIES = 4;
const isChartLimitReached = trackedIds.size >= MAX_CHART_ENTITIES;
const isCurrentEntityTracked = selectedEntity ? trackedIds.has(selectedEntity.id) : false;
const isChartDisabled = isChartLimitReached && !isCurrentEntityTracked;
```

逻辑：如果已达上限但当前实体已启用图表，仍可关闭（disabled=false）；如果已达上限且当前实体未启用，则禁用（disabled=true）。

**修改 B) 常规实体编辑器的图表追踪 Switch (line ~763)**

将：
```tsx
<Switch
  checked={trackedIds.has(selectedEntity.id)}
  onCheckedChange={() => toggleTracking(selectedEntity.id)}
/>
```

改为：
```tsx
<div className="flex items-center justify-between">
  <div className="flex flex-col">
    <label className="text-xs text-[hsl(var(--muted-foreground))]">图表追踪</label>
    {isChartDisabled && (
      <span className="text-[10px] text-[hsl(var(--destructive))] mt-0.5">
        图表已达上限 — 同时最多 4 个实体启用图表，请先移除其他实体的图表
      </span>
    )}
  </div>
  <Switch
    checked={trackedIds.has(selectedEntity.id)}
    onCheckedChange={() => toggleTracking(selectedEntity.id)}
    disabled={isChartDisabled}
  />
</div>
```

**修改 C) 弹簧编辑器的图表追踪 Switch (line ~513)**

在弹簧实体编辑部分的「图表追踪」行进行相同修改（弹簧实体同样计入 chart 上限）。
