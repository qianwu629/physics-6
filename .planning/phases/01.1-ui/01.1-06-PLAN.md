**C-02 修复 (Draggable + Resizable ref 冲突):**

当前代码：`<Draggable nodeRef={panelRef}> <Resizable ref={panelRef}> ... </Resizable> </Draggable>`
问题：panelRef 同时被 Draggable.nodeRef 和 Resizable.ref 使用，产生冲突。

修复方式 — 将 ref 分离为两个独立的：

```tsx
const dragRef = useRef<HTMLDivElement>(null);
const resizeRef = useRef<Resizable>(null);

// 在 Resizable 上使用 resizeRef，外层用 dragRef
<Draggable
  nodeRef={dragRef}
  handle=".panel-header"
  bounds="parent"
  cancel=".react-resizable-handle, button, .panel-body"
>
  <div ref={dragRef} style={{ position: 'fixed', right: '16px', top: '80px' }}>
    <Resizable
      ref={resizeRef}
      defaultSize={{ width: 480, height: 320 }}
      minWidth={320}
      minHeight={200}
      maxWidth={1200}
      maxHeight={800}
      enable={{
        top: false,
        right: true,
        bottom: true,
        left: false,
        topRight: false,
        bottomRight: true,
        bottomLeft: false,
        topLeft: false,
      }}
      handleClasses={{
        right: 'react-resizable-handle-right',
        bottom: 'react-resizable-handle-bottom',
        bottomRight: 'react-resizable-handle-bottom-right',
      }}
      onResizeStop={() => {
        chartCanvasRef.current?.refreshAll();
      }}
    >
      {/* 内部 panel-container div */}
    </Resizable>
  </div>
</Draggable>
```

关键变更：
1. 外层 div（dragRef）承载 position:fixed + right/top 定位

3. Resizable 的 defaultSize 改为 480×320（UI-SPEC §2 规定: 默认 480×320）

修复 ChartCanvas.tsx 中分离模式下的渲染 bug。

**C-03 根因分析:**
当 ChartPanel layoutMode 切换为 'separate' 时，ChartPanel.tsx 为每个 entity 渲染独立的 ChartCanvas 实例（lines 159-165）。由于每个 entity div 使用 `min-h-[120px]` 且 ChartCanvas 使用 `useEffect([], [])` 的 ResizeObserver 初始化方式，多个 ChartCanvas 实例同时挂载/卸载时 ResizeObserver 可能未正确清理或重新挂载。

**修复方案 — 稳定 ResizeObserver 生命周期:**

1. 在 ChartCanvas 的 useEffect cleanup 中，增加对 chartRef 和 ResizeObserver 的更完整清理：

```tsx
useEffect(() => {
  const container = containerRef.current;
  if (!container) return;

  const chart = createChart(container, { ... });
  chartRef.current = chart;

  const ro = new ResizeObserver((entries) => {
    // 使用 requestAnimationFrame 防抖，避免分离模式下多个实例同时 resize
    requestAnimationFrame(() => {
      if (!chartRef.current) return;
      const { width, height } = entries[0].contentRect;
      // 宽高为 0 时跳过（容器尚未布局完成）
      if (width === 0 || height === 0) return;
      chart.applyOptions({ width, height });
    });
  });
  ro.observe(container);

  return () => {
    ro.disconnect();
    // 确保 chart 在 remove 前停止接受数据
    chart.remove();
    chartRef.current = null;
    seriesMapRef.current.clear();
  };
}, []);
```

关键变更：
- ResizeObserver 回调包裹 `requestAnimationFrame` 防抖
- 宽高 0 检查避免空容器 resize
- cleanup 中 `chart.remove()` 在 `ro.disconnect()` 后执行

2. 添加 CSS min-height 保证容器有初始尺寸：

```tsx
<div
  ref={containerRef}
  className="absolute inset-0"
  style={{ minHeight: '120px' }}
/>
```

改为 absolute 定位以确保填充父容器（替代 width/height:100%）。
