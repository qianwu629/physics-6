## 研究结论（08-RESEARCH-CODE.md §4.3）

FieldSourceComponent 设计：
- kind: 'charge' | 'current'
- charge 复用 RigidBodyComponent.charge（避免数据冗余，per D-08-07 选项A）
- current: { magnitude: number; direction: [number, number, number] }
- timeVarying: { enabled: boolean; amplitude: number; frequency: number; phase: number }

      enabled: boolean;
      amplitude: number;      // 振幅（与 base 值同单位）
