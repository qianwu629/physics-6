### Panel 2: Spring Creation Mode（弹簧创建模式）

**触发**: 点击 Toolbox "弹簧" 按钮 (Q1-A)
**形态**: 状态机 —— 进入"弹簧创建模式"，退出时恢复

```
状态机:
  IDLE → SPRING_MODE_PENDING → (两个实体已选) → CREATION_DIALOG → IDLE

  IDLE ──[点击 Toolbox 弹簧按钮]──→ SPRING_MODE_PENDING
      ──[Escape / 右键 / 再次点弹簧按钮]──→ IDLE
```

**SPRING_MODE_PENDING 状态**:
```
┌─ Toolbar 上方中央提示横幅 ──────────────────────────────────────┐
│  〰 弹簧创建模式 — 点击场景中第一个实体（锚点 A），或按 Esc 取消  │
└──────────────────────────────────────────────────────────────────┘
```

**Step 1 — 选择实体 A**:
- 鼠标移到场景中任何实体上时，该实体高亮为绿色描边（`#22c55e`），提示"可作为弹簧端点"
- 点击实体 A → 实体 A 固定绿色描边，提示文字变为 "已选「实体A名称」— 点击第二个实体（锚点 B）"

**Step 2 — 选择实体 B**:
- 鼠标移到其他实体上时绿色高亮，已选的实体 A 保持绿色描边
- 点击实体 B → 弹出参数对话框
- 若再次点击实体 A → 取消选择，回到 Step 1 状态

**Step 3 — 参数对话框**:
```
┌──────────────────────────────────────┐
│  添加弹簧                      [×]  │
├──────────────────────────────────────┤
│                                      │
│  端点 A: 球体-1                      │
│  端点 B: 方块-1                      │
│  ─────────────────────────────       │
│                                      │
│  弹性系数 (k)                        │
│  [━━━━●━━━━━] 100 N/m               │  ← Slider + NumberInput
│                                      │
│  原长 (L₀)                           │
│  [━━━━●━━━━━] 2.00 米               │
│                                      │
│  阻尼系数                            │
│  [━━━━●━━━━━] 0.10                  │
│                                      │
│              [  取消  ]  [  确认添加  ] │
└──────────────────────────────────────┘
```

- **Width**: 380px, centered on screen
- **样式**: 复用 Phase 2 CreationDialog 规范
  - Backdrop: `rgba(0, 0, 0, 0.6)` + `backdrop-filter: blur(4px)`
  - Panel: glassmorphic, `rgba(26, 26, 26, 0.95)`, border-radius 16px, padding 24px
- **端点标签**: 14px, weight 400, `#e0e0e0`，左侧形状图标 `#3b82f6`
- **Slider range**: k: 0–500 N/m, L₀: 0.1–20 m, damping: 0–1
- **取消**: 关闭对话框，退出弹簧创建模式，实体 A/B 的绿色描边清除
- **确认**: 创建弹簧、关闭对话框、退出弹簧模式、弹簧自动选中（PropertyPanel 显示弹簧属性）

**弹簧创建模式取消路径**:
- Escape 键
- 在对话框中点"取消"
- 右键
- 再次点击 Toolbox 弹簧按钮

### Panel 4: Spring 3D Visualization（弹簧 3D 渲染）

**方案**: Helix tube（螺旋管），Q2-A

**默认外观**:
- **几何**: Tubular helix，6-8 全圈，沿两实体接触点连线分布
- **粗细**: 管半径 0.08 米（场景单位）
- **材质**: `MeshStandardMaterial`, `roughness: 0.4`, `metalness: 0.1`
- **颜色**: 自然长时 `#c0c0c0`（银灰色金属感）
  - 压缩态 (< L₀): 红移 → `#e06060`（浅红，压缩越强红越深）
  - 拉伸态 (> L₀): 蓝移 → `#6080e0`（浅蓝）
  - 颜色过渡: `mixColor` 沿 L/L₀ 比例线性插值
- **端点**: 两端各一个小球体（r = 0.15m），颜色跟随弹簧主色
- **性能**: 每根弹簧 ~200-400 三角形（low-poly tube），10 根弹簧内不创建 LOD

**选中态 (Q3-A)**:
- 弹簧被选中时，整段 helix tube 周围渲染 Outlines (drei)，颜色 `#3b82f6`，lineWidth 2px
- 两端实体同时点亮 Outlines（提示"这两个实体与弹簧关联"），颜色 `#a0d0ff`
- 脉冲动画: opacity 0.6→1.0，周期 2s（与实体选中动画一致）

**端点实体的弹簧提示**:
- 选中实体时，即使未选中其上的弹簧，从该实体发出的弹簧管线也略微变亮 (+15% opacity)，以示"本实体参与弹簧"

### Panel 5: Global Multiplier Visual Feedback（全局倍率视觉反馈）

PropertyPanel 实体属性中需展示全局倍率的影响 (D-08):

```
实体属性 (暂停，可编辑):
───────────────────────
摩擦系数
  实体: 0.3  ×  全局: 1.0  =  实际: 0.3
  [━━●━━━━━]     (🌐 1.0×)      ← 滑块可调实体值，全局倍率标注

弹性系数
  实体: 0.5  ×  全局: 0.5  =  实际: 0.25
  [━━●━━━━━]     (🌐 0.5× 🔔)  ← 倍率非 1.0 时加 🔔 标记

```

- **布局**: 每个受倍率影响的参数行改为三行级联
  - Row 1: `实体: {value}` `×` `全局: {multiplier}` `=` `实际: {result}`（14px, mono, `#888`, letter-spacing 0.02em）
  - Row 2: 滑块（正常） + `(🌐 {multiplier}×)` 标签
  - Row 3: 若 multiplier ≠ 1.0 → 显示 `实际: {result}` 高亮 `#a0d0ff`（14px, mono, letter-spacing 0.02em）
- **倍率标签**: 14px, bg `rgba(59,130,246,0.1)`, rounded 4px, padding 2px 8px
- **倍率 ≠ 1.0 标记**: 🔔 图标 (Lucide `AlertTriangle`, 尺寸 14px), color `#e9c46a`，无声音

## Edge Cases & Error Handling

| Situation | Behavior |
|-----------|----------|
| 弹簧端点重合 (L = 0) | 创建对话框显示警告 "原长不能为 0"，确认按钮 disabled。预设 L₀ = 当前两点距离。 |
| 弹性系数 k = 0 | 创建对话框允许（k=0 的弹簧不产生力，等同无弹簧）。确认不阻拦，但 PropertyPanel 底部显示 🔔 "弹性系数为 0，弹簧无作用力" |
| 删除实体 (Spring created) | 级联删除该实体上的所有弹簧（无额外确认弹窗），删除后若无选中则 PropertyPanel 回退空状态 |
| 弹簧创建模式中多次点同一实体 | 显示 "锚点 A 与锚点 B 不可为同一实体" 瞬间闪红，不退出模式 |
| 弹簧创建模式中点地面/参考网格 | 忽略（地面不是实体），不退出模式 |
| 环境中调整倍率到 0 | 允许（倍率=0 视为 0 摩擦/0 弹性），PropertyPanel 中实体摩擦实际值显示 0，🔔 标记出现 |
| 极端的空气阻力值 | 拖动 0-2.0 范围，极端值允许。空气阻力 > 1.0 会导致物体几乎无法运动（符合预期） |
| 弹簧超过最大推荐数 | Phase 3 不设硬上限；但 EntityList 中超过 8 条弹簧时，弹簧分组自动折叠（可展开） |
| 暂停/播放切换 (弹簧属性面板打开) | 自动切换 Editable ↔ Read-only 状态（复用 Phase 2 PropertyPanel 状态切换）。编辑中的值已写入 store，不丢失。 |
