## 环境参数面板位置

### 第 1 题：面板载体

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 顶部 Toolbar 插槽→弹出面板 | Toolbar 增"环境"按钮，点击弹出独立浮动面板。与现有顶部毛玻璃 Toolbar 风格一致。 | ✓ |
| (B) 底部抽屉式（可展开/收起） | 默认隐藏，点击抹头按钮展开占屏幕下方一条。 | |
| (C) PropertyPanel 新增"全局"标签页 | 现有右侧 PropertyPanel 顶部增"实体" / "全局"切换。 | |
| (D) 左下角常驻环境面板 | 类似左侧 Toolbox，左下方独立常驻。 | |

**User's choice:** (A) 顶部 Toolbar 插槽→弹出面板
**Notes:** 与 Phase 1 D-07 顶部浮动 Toolbar 设计一脉相承，不占据常驻屏幕空间。

### 第 2 题：输入控件类型

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 纯滑块 | 拖动反馈直接，但精确值难输入 | |
| (B) 滑块 + 数字输入（双轨） | 与 Phase 2 PropertyPanel 一致 | |
| (C) 预设值快选 + 自定义 | 高中场景映射明确，但不够自由 | |
| (D) 预设胶囊 + 滑块 + 输入框 | 三合一最全能 | ✓ |

**User's choice:** (D) 预设胶囊 + 滑块 + 输入框
**Notes:** 高中物理常见预设（地球/月球/火星/无重力）作为"快选锚点"，滑块和输入框承担精细调节。映射用户的高中物理教学定位。

### 第 3 题：重力方向

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 仅预设方向选项（6面） | -Y, +Y, +X, -X, +Z, -Z + 零重力 | |
| (B) X/Y/Z 分量输入框 | 三个数字输入，默认 (0, -9.81, 0) | ✓ |
| (C) 大小滑块 + 预设方向胶囊 | 大小与方向分离的物理课本表达 | |
| (D) 3D 可拖拽箭头 gizmo | 视觉炫但开发复杂 | |

**User's choice:** (B) X/Y/Z 分量输入框
**Notes:** 用户偏向数学化精确表达，与高中物理"自己拆分量、自己算"思维契合。重力大小由分量隐式表达，无须独立维度。

### 第 4 题：重置范围

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 全重置（实体+环境） | 重置 = 一切回到初始状态 | |
| (B) 仅重置实体，环境保留 | 适合"同一环境下试不同物体" | ✓ |
| (C) 分类重置（两按钮） | 提供独立的"重置环境为默认"按钮 | |

**User's choice:** (B) 仅重置实体，环境保留
**Notes:** 适配教学场景"重力调到月球档，反复添加不同物体测试自由落体"。用户表达"试不同场景"是核心需求。

## 运行时编辑策略

### 第 1 题：核心策略

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 严格遵 D-09：均仅暂停可改 | 设计一致性优先，所有参数只在暂停时可改 | ✓ |
| (B) 环境参数例外，运行时可调 | 教学价值高（"实时调重力看变化"） | |
| (C) 折中：仅重力/空气阻力实时可调 | 摩擦系数因技术原因仍仅暂停 | |

**User's choice:** (A) 严格遵 D-09：均仅暂停可改
**Notes:** 用户取向是设计一致性优先于实时调参的教学便利。这是 Phase 3 最关键的取舍——明确放弃"实时改重力"的炫技场景，换取整体心理模型简单。

### 第 2 题：运行态 UI

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 只读 + 反转提示 | 控件 disabled、变灰，面板顶部"运行中，请暂停后编辑" | ✓ |
| (B) 可调但不生效 | UI 看起来能改但实际不应用 | |
| (C) 试点开便提示暂停 | 弹窗提示"调整需要暂停仿真，是否暂停？" | |
| (D) 点开面板自动暂停 | 自动暂停 + 打开面板可编辑 | |

**User's choice:** (A) 只读 + 反转提示
**Notes:** 与 Phase 2 D-09 PropertyPanel 只读态视觉一致。延续既有 UI 模式。

### 第 3 题：生效时机

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 立即生效 | 拖滑块/输入数字立即写入 store，下次物理步长应用 | |
| (B) Apply 按钮手动提交 | 多参数批量预览后一起提交 | |
| (C) 立即生效 + 预览动画 | 立即写入 + DOM 高亮闪烁反馈 | ✓ |

**User's choice:** (C) 立即生效 + 预览动画
**Notes:** 与 Phase 2 D-10 行为一致，添加视觉反馈强化"改动已生效"的感知。

### 第 4 题：全局与实体参数关系

| Option | Description | Selected |
|--------|-------------|----------|
| (A) 全局 = 新实体默认值 | 现有实体不受影响 | |
| (B) 全局强制覆盖实体 | "一键冰面"快速但破坏自定义 | |
| (C) 全局作为倍率法修正 | 实际值 = 实体参数 × 全局倍率 | ✓ |
| (D) 废除实体级，仅保留全局 | 倒退 Phase 2 已交付能力 | |

**User's choice:** (C) 全局作为倍率法修正
**Notes:** 用户清楚 Phase 2 已交付的实体级摩擦/弹性是核心能力，倍率叠加是数学上最优雅的"两者并存"方案。技术实现需要 Rapier `combineRule` 重建。
