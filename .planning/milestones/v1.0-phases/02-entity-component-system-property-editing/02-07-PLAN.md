### Gap 1 Source Diagnosis (from UAT)
- creationSchema 缺少 positionX/positionY/positionZ 字段
- 表单未渲染位置输入区域
- handleConfirm 中工厂调用未传递 position 参数
- Entity.ts 工厂函数（createSphereEntity, createBoxEntity, createCylinderEntity, createSlopeEntity）均已支持可选 position 参数，无需更改

### Gap 2 Source Diagnosis (from UAT)
- uiSlice 缺少 propertyPanelCollapsed 状态
- App.tsx 中 PropertyPanel 被无条件渲染
- PropertyPanel X 按钮 onClick 仅执行 selectEntity(null)，未切换面板可见性
- 左侧 Toolbox 已有 toolboxCollapsed/toggleToolbox 模式可供参考

### Existing Pattern Reference (from Toolbox)
Toolbox 折叠模式的实现方式（用于 Gap 2 仿照）:
- uiSlice: `toolboxCollapsed: boolean` + `toggleToolbox: () => void`（初始值 false——默认展开）
- Toolbox.tsx: 根据 `toolboxCollapsed` 状态切换渲染"+"按钮（折叠时）或完整按钮组+X 按钮（展开时）
- App.tsx: 无条件渲染 `<Toolbox />`（折叠/展开逻辑在组件内部）

PropertyPanel 的对应模式:
- uiSlice: `propertyPanelCollapsed: boolean` + `togglePropertyPanel: () => void`（初始值 false——默认展开）
- App.tsx: 条件渲染 `{!propertyPanelCollapsed && <PropertyPanel />}`
- 折叠时在 App.tsx 中渲染一个小型浮动重新打开按钮（类似 Toolbox 的"+"），位于右下角（right:16px, top:80px），点击调用 `togglePropertyPanel()`

**步骤 C: HandleConfirm 中传递 position**
