**视觉层级**:
1. 3D 场景中的物理物体（主焦点）
2. 选中物体的高亮描边（蓝色 glow）
3. 工具栏控制按钮（次要交互）
4. 左侧工具箱 + 右侧属性面板（编辑交互）
5. 状态指示器（帧率、物体计数）

### Panel 1: Left-Side Floating Toolbox（左侧浮动工具箱）

```
┌────────────┐
│ ┌────────┐ │
│ │  ⬤   │ │  ← 球体 (Sphere) — aria-label="添加球体"
│ └────────┘ │
│ ┌────────┐ │
│ │  ■   │ │  ← 方块 (Box) — aria-label="添加方块"
│ └────────┘ │
│ ┌────────┐ │
│ │  ◯   │ │  ← 圆柱 (Cylinder) — aria-label="添加圆柱"
│ └────────┘ │
│ ┌────────┐ │
│ │  ╱╲  │ │  ← 斜面 (Slope) — aria-label="添加斜面"
│ └────────┘ │
│     ✕      │  ← 折叠/展开切换按钮（展开时显示在底部）
└────────────┘
```

- **Position**: `fixed`, `left: 16px`, `top: 50%`, `transform: translateY(-50%)`, `z-index: 40`
- **Size**: 48px × 4 buttons = ~208px height (expanded), 48px × 1 = 48px (collapsed)
- **Style**: glassmorphic — `rgba(26, 26, 26, 0.85)` + `backdrop-filter: blur(8px)` + `border: 1px solid rgba(255,255,255,0.06)`
- **Button size**: 40px × 40px, icon 20px, centered
- **Button gap**: 8px (sm token)
- **Border radius**: 12px (panel), 8px (buttons)
- **Collapsed state**: 仅显示一个 "+" 图标按钮，点击展开
- **Hover**: 按钮背景 `rgba(59, 130, 246, 0.15)`，图标色 `#3b82f6`
- **Active/pressed**: 按钮背景 `rgba(59, 130, 246, 0.3)`，缩放 0.95

### Read-Only vs Editable States（属性面板）

**Editable state（仿真暂停时）**:
```
┌──────────────────────┐
│ 实体属性        [×]  │
├──────────────────────┤
│ ● 球体-1  ■ 方块-1  │
├──────────────────────┤
│ ┌────────────────┐   │
│ │  ● 可编辑       │   │  ← 状态徽章: 白色边框 + 绿色圆点
│ └────────────────┘   │
│ 质量: [━━━●━━] 1.0   │  ← Slider 可拖拽
│ 弹性: [━━●━━━] 0.5   │
│ ...                  │
└──────────────────────┘
```
- Panel border: `1px solid rgba(255, 255, 255, 0.12)` (白色，较明显)
- Input fields: 正常背景 `#222`，白色文字，可交互
- Sliders: 正常蓝色轨道 `#3b82f6`
- Status badge: "可编辑" — 绿色圆点 `#22c55e` + 文字 "可编辑"

**Read-only state（仿真运行时）**:
```
┌──────────────────────┐
│ 实体属性        [×]  │
├──────────────────────┤
│ ● 球体-1  ■ 方块-1  │
├──────────────────────┤
│ ┌────────────────┐   │
│ │  ⏸ 只读        │   │  ← 状态徽章: 灰色边框 + 灰色圆点
│ └────────────────┘   │
│ 质量: 1.0 kg         │  ← 纯文本显示，无滑块
│ 弹性: 0.5            │
│ ...                  │
└──────────────────────┘
```
- Panel border: `1px solid rgba(255, 255, 255, 0.06)` (灰色，淡化)
- Input fields: 隐藏，替换为只读文本 `#666`
- Sliders: 隐藏，替换为 "数值 + 单位" 文本
- Status badge: "只读" — 灰色圆点 `#666` + 文字 "只读 — 暂停后可编辑"
- All inputs: `disabled` attribute set, `pointer-events: none`
- Entity list: 仍可点击切换选中（只影响高亮，不影响编辑）

### Panel 4: 3D Selection Highlight（3D 选中高亮）

- **Effect**: 选中实体周围渲染 `Outlines` ( drei ) 或自定义 `LineLoop` 几何描边
- **Color**: `#3b82f6` (accent blue-500)
- **Line width**: 2px (在屏幕空间)
- **Opacity**: 0.8
- **Animation**: 轻微脉冲效果 — opacity 在 0.6~1.0 之间以 2s 周期正弦波动
- **Depth test**: disabled (确保描边始终可见，即使被其他物体遮挡)
- **Multiple selection**: Phase 2 仅支持单选，后续 Phase 可扩展多选

### Screen Reader Support

- 所有图标按钮必须有 `aria-label`（无可见文字时）
- 对话框打开时设置 `aria-modal="true"`，焦点 trapped 在对话框内
- 实体列表使用 `role="list"`，列表项使用 `role="listitem"`
- 选中状态通过 `aria-selected="true"` 传达
- 只读/可编辑状态通过 `aria-readonly` 或 live region 宣布
- 删除确认对话框使用 `role="alertdialog"`
- 颜色选择器使用 `role="radiogroup"`，色块使用 `role="radio"`

### Color Contrast

- 所有文字对比度符合 WCAG AA（4.5:1）
- 输入框文字 `#fafafa` on `#222222` = 14.8:1 — PASS
- 标签文字 `#a0a0a0` on `#1a1a1a` = 7.2:1 — PASS
- 只读数值 `#666666` on `#1a1a1a` = 4.6:1 — PASS
- 禁用状态文字 `#444444` on `#1a1a1a` = 2.8:1 — 仅用于禁用，不用于可读内容
