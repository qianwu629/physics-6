# Plan 04-04: UI 控制集成与 UAT

## Objective
在 Toolbar 和 PropertyPanel 中集成可视化控制，完成端到端功能验证和用户验收测试（UAT），确认 Phase 4 全部 5 项成功标准满足。

## must_haves
- Toolbar 新增 4 个按钮：轨迹 toggle、速度 toggle、受力 toggle、显示范围切换（全部/选中）
- PropertyPanel 每个实体底部显示"显示轨迹"和"显示矢量"开关
- 开关状态与 visualizationStore/ECS 组件同步
- UAT 5 项成功标准全部通过
- 性能达标（50 物体 + 全开可视化 ≥ 55 FPS）

## truths
- 可视化控制是显示开关，非编辑操作——运行中和暂停均可切换
- Toolbar 按钮使用 shadcn Button（variant=ghost vs default）
- PropertyPanel 开关使用 shadcn Switch 组件

### Task 1: 扩展 Toolbar 添加可视化控制按钮

<read_first>
- frontend/src/components/Toolbar.tsx

- frontend/src/store/visualizationStore.ts
- .planning/01-UI-SPEC.md（UI 规范）

<action>
在 `frontend/src/components/Toolbar.tsx` 中：

1. 导入 `useVisualizationStore`：
```typescript
import { useVisualizationStore, VectorDisplayMode } from '../store/visualizationStore';
```

2. 提取状态和 actions：
```typescript
const {
  showTrails, showVelocityVectors, showForceVectors, vectorDisplayMode,
  toggleTrails, toggleVelocityVectors, toggleForceVectors, setVectorDisplayMode,
} = useVisualizationStore();
```

3. 在环境按钮之后添加可视化按钮组（用 `border-l border-white/10 pl-2` 分隔）：
```tsx
<div className="flex items-center gap-1 pl-1 border-l border-white/10">
  <button
    onClick={toggleTrails}
    className={cn(
      'px-2 py-1 text-xs rounded',
      showTrails ? 'bg-white/15 text-white' : 'text-white/50 hover:text-white/80'
    )}
    title={showTrails ? '隐藏轨迹' : '显示轨迹'}
  >
    轨迹
  </button>
  <button
    onClick={toggleVelocityVectors}
    className={cn(
      'px-2 py-1 text-xs rounded',
      showVelocityVectors ? 'bg-white/15 text-white' : 'text-white/50 hover:text-white/80'
    )}
    title={showVelocityVectors ? '隐藏速度矢量' : '显示速度矢量'}
  >
    速度
  </button>
  <button
    onClick={toggleForceVectors}
    className={cn(
      'px-2 py-1 text-xs rounded',
      showForceVectors ? 'bg-white/15 text-white' : 'text-white/50 hover:text-white/80'
    )}
    title={showForceVectors ? '隐藏受力矢量' : '显示受力矢量'}
  >
    受力
  </button>
  <button
    onClick={() =>
      setVectorDisplayMode(
        vectorDisplayMode === 'all' ? 'selected' : 'all'
      )
    }
    className="px-2 py-1 text-xs rounded text-white/50 hover:text-white/80"
    title={vectorDisplayMode === 'all' ? '仅显示选中实体' : '显示全部实体'}
  >
    {vectorDisplayMode === 'all' ? '全部' : '选中'}
  </button>
</div>
```

按钮需适配现有 Toolbar 的 className 模式（cn 或直接用字符串类名）。
</action>

<acceptance_criteria>
- `Toolbar.tsx` 渲染 4 个新按钮：轨迹、速度、受力、全部/选中
- 轨迹/速度/受力按钮在 active 状态有视觉区分（`bg-white/15` vs `text-white/50`）
- 显示范围按钮在"全部"和"选中"之间切换文案
- 按钮组与环境按钮之间有 `border-l` 分隔
- 点击按钮触发对应 store action
</acceptance_criteria>

### Task 2: 扩展 PropertyPanel 添加按实体开关

<read_first>
- frontend/src/components/PropertyPanel.tsx
- frontend/src/components/ui/switch.tsx
- frontend/src/store/entitySlice.ts
- frontend/src/ecs/types.ts（TrailComponent / VectorComponent）
</read_first>

<action>
在 `frontend/src/components/PropertyPanel.tsx` 中，为每个实体的属性列表底部添加可视化开关区域：

1. 导入 toggle actions：
```typescript
import { toggleTrailVisibility, toggleVectorVisibility } from '../store/entitySlice';
```

2. 在 entity 属性渲染底部（物理参数之后）添加：
```tsx
{/* 可视化开关 */}
<div className="pt-2 mt-2 border-t border-white/10 space-y-1.5">
  <div className="flex items-center justify-between">
    <label className="text-xs text-white/60">显示轨迹</label>
    <Switch
      checked={trailComp?.visible ?? true}
      onCheckedChange={(v) => toggleTrailVisibility(entity.id, v)}
    />
  </div>
  <div className="flex items-center justify-between">
    <label className="text-xs text-white/60">显示矢量</label>
    <Switch
      checked={vectorComp?.showVelocity ?? true}
      onCheckedChange={(v) => toggleVectorVisibility(entity.id, v)}
    />
  </div>
</div>
```

其中 `trailComp` 和 `vectorComp` 从 `entity.components.get('trail')` / `.get('vector')` 读取。
</action>

<acceptance_criteria>
- PropertyPanel 为每个实体渲染"显示轨迹"和"显示矢量"两个 Switch
- Switch 状态与 entity 的 `trail.visible` / `vector.showVelocity` 同步
- toggle action 通过 `useSimulationStore` 的 setState 触发
- 开关区域位于属性面板底部，用 `border-t` 分隔
</acceptance_criteria>
