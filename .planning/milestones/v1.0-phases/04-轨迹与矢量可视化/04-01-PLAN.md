# Plan 04-01: 可视化基础层（类型 + 状态 + 缓冲区）

## Objective
建立 Phase 4 的可视化基础：定义 ECS 组件类型（TrailComponent + VectorComponent）、创建独立的 visualizationStore、实现 TrajectoryBuffer 环形缓冲区数据结构。此 plan 为 Wave 1 唯一项，完成后 04-02（轨迹渲染）和 04-03（矢量箭头）可并行开发。

## must_haves
- `TrailComponent` + `VectorComponent` 在 ECS types 中定义
- `entitySlice` 导出 `toggleTrailVisibility` 和 `toggleVectorVisibility` reducer
- `visualizationStore` 管理全局开关状态（showTrails/showVelocityVectors/showForceVectors/vectorDisplayMode）
- `TrajectoryBuffer` 类：Float32Array 预分配环形缓冲区，max 300 点 + 5 秒时间限制

## truths
- PITFALLS #6：visualizationStore 仅存开关状态，每帧数据用 useRef
- 可视化控制是开关，非编辑操作——运行中和暂停均可切换
- 独立 store（非组合进 useSimulationStore），通过 persist middleware 持久化

```typescript
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

export type VectorDisplayMode = 'all' | 'selected';

interface VisualizationState {
  showTrails: boolean;
  showVelocityVectors: boolean;
  showForceVectors: boolean;
  vectorDisplayMode: VectorDisplayMode;

  toggleTrails: () => void;
  toggleVelocityVectors: () => void;
  toggleForceVectors: () => void;
  setVectorDisplayMode: (mode: VectorDisplayMode) => void;
}

export const useVisualizationStore = create<VisualizationState>()(
  persist(
    (set) => ({
      showTrails: true,
      showVelocityVectors: false,
      showForceVectors: false,
      vectorDisplayMode: 'all',

      toggleTrails: () => set((s) => ({ showTrails: !s.showTrails })),
      toggleVelocityVectors: () =>
        set((s) => ({ showVelocityVectors: !s.showVelocityVectors })),
      toggleForceVectors: () =>
        set((s) => ({ showForceVectors: !s.showForceVectors })),
      setVectorDisplayMode: (mode) => set({ vectorDisplayMode: mode }),
    }),
    { name: 'physis-visualization' }
  )
);
```

此为独立 store（非组合进 `useSimulationStore`），与现有 store 模式一致。

### Task 4: 实现 TrajectoryBuffer

<read_first>
- .planning/phases/04-轨迹与矢量可视化/04-RESEARCH.md §1.3
</read_first>

<action>
创建 `frontend/src/ecs/TrajectoryBuffer.ts`：

```typescript
import { Vector3 } from 'three';

const MAX_POINTS = 300;
const MAX_AGE_SECONDS = 5;
const STRIDE = 3;

export class TrajectoryBuffer {
  private positions: Float32Array;
  private timestamps: Float32Array;
  private head = 0;
  private count = 0;

  constructor() {
    this.positions = new Float32Array(MAX_POINTS * STRIDE);
    this.timestamps = new Float32Array(MAX_POINTS);
  }

  push(position: Vector3, time: number): void {
    const idx = this.head * STRIDE;
    this.positions[idx] = position.x;
    this.positions[idx + 1] = position.y;
    this.positions[idx + 2] = position.z;
    this.timestamps[this.head] = time;
    this.head = (this.head + 1) % MAX_POINTS;
    this.count = Math.min(this.count + 1, MAX_POINTS);
  }

  // 返回按时间顺序排列的点（旧→新），裁掉超过5秒的旧数据
  getPoints(currentTime: number): { positions: Vector3[]; count: number } {
    const result: Vector3[] = [];
    const cutoff = currentTime - MAX_AGE_SECONDS;

    const start = this.count < MAX_POINTS ? 0 : this.head;
    let validCount = 0;
    for (let i = 0; i < this.count; i++) {
      const bufIdx = (start + i) % MAX_POINTS;
      if (this.timestamps[bufIdx] >= cutoff) {
        const pIdx = bufIdx * STRIDE;
        result.push(
          new Vector3(this.positions[pIdx], this.positions[pIdx + 1], this.positions[pIdx + 2])
        );
        validCount++;
      }
    }

    return { positions: result, count: validCount };
  }

  clear(): void {
    this.head = 0;
    this.count = 0;
  }

  getCount(): number {
    return this.count;
  }
}
```

关键设计：同时存储位置 + 时间戳，`getPoints` 自动裁剪超过 5 秒的旧数据（D-02 双限制）。
</action>

<acceptance_criteria>
- `frontend/src/ecs/TrajectoryBuffer.ts` 存在且导出 `TrajectoryBuffer`
- 构造函数预分配 `Float32Array(MAX_POINTS * 3)` 位置 + `Float32Array(MAX_POINTS)` 时间戳
- `push(position, time)` 接受 `Vector3` 和秒级时间戳

</acceptance_criteria>
