## 轨迹采样与存储策略

| Option | Description | Selected |
|--------|-------------|----------|
| 每帧记录（120Hz） | 最平滑的轨迹线条，但内存增长快。50个物体运行10秒 = 6万个点。 | |
| 降采样（如每3帧或30Hz） | 牺牲一点平滑度换取3倍内存节省。50个物体10秒 = 2万个点。对抛体运动等高中物理场景完全够用。 | ✓ |
| 你决定 | Claude 根据实现复杂度自行判断最佳方案。 | |

**User's choice:** 降采样（如每3帧或30Hz）
**Notes:** 对高中物理教学场景，30Hz 足够平滑，内存开销可控。

---

| Option | Description | Selected |
|--------|-------------|----------|
| 按时间限制（如最近5秒） | 与模拟时间挂钩，直观。高速运动物体轨迹更长、低速更短，符合物理直觉。 | |
| 按点数限制（如最近500个点） | 内存占用固定，与运动速度无关。高速物体轨迹被截断，低速物体保留更久历史。 | |
| 两者结合（最大300点 + 最长5秒） | 内存和时间双保险，但实现略复杂。高速短截断、低速长历史，同时防止极端场景内存泄漏。 | ✓ |

**User's choice:** 两者结合（最大300点 + 最长5秒）
**Notes:** 双保险策略，先触发者截断。

## 受力矢量的信息来源与显示粒度

| Option | Description | Selected |
|--------|-------------|----------|
| 仅已知力（重力 + 弹力 + 空气阻力） | 从 store 的环境参数和 ECS 组件直接计算。实现简单、确定性高。但不包含碰撞/摩擦接触力。 | |
| 已知力 + 从 Rapier 碰撞事件估算接触力 | 监听 collision events，结合动量变化估算接触力大小和方向。能显示碰撞冲击，但实现复杂、数值不精确。 | ✓ |
| 已知力 + 从线加速度反推合力 | 用 Rapier 提供的线加速度 × 质量反推合力，减去已知力后得到"其他力"。显示为一个"其他力"箭头。 | |
| 你决定 | Claude 自行判断最佳方案。 | |

**User's choice:** 已知力 + 从 Rapier 碰撞事件估算接触力
**Notes:** 功能最全面，接触力估算通过 collision events + 动量变化实现。

---

| Option | Description | Selected |
|--------|-------------|----------|
| 每个分力独立箭头 | 重力一个箭头、弹力一个箭头、空气阻力一个箭头、接触力一个箭头。信息最完整，但箭头多可能视觉混乱。 | |
| 仅合力箭头 | 只有一个箭头代表所有力的矢量和。最简洁，但看不清各分力的贡献。 | |
| 分力 + 合力并存 | 默认显示所有分力，再加一个粗一点的合力箭头。最全面但最复杂，视觉上需要精心设计避免混乱。 | ✓ |
| 你决定 | Claude 自行判断。 | |

**User's choice:** 分力 + 合力并存
**Notes:** 细线箭头表示各分力，粗线箭头表示合力。

---

| Option | Description | Selected |
|--------|-------------|----------|
| 速度一色 + 受力一色 | 所有速度箭头蓝色，所有受力箭头红色。简单，一眼区分两类矢量。 | |
| 速度一色 + 分力分色 + 合力深色 | 速度统一蓝色。各分力用不同颜色（重力灰、弹力绿、接触力红、阻力黄），合力用粗白箭头。信息密度最高。 | ✓ |
| 速度一色 + 受力统一色 | 速度蓝色，受力橙色。比方案2简洁但比分力分色信息少。 | |
| 你决定 | Claude 自行判断。 | |

**User's choice:** 速度一色 + 分力分色 + 合力深色
**Notes:** 颜色映射：速度=蓝、重力=灰、弹力=绿、接触力=红、阻力=黄、合力=白粗线。

---

| Option | Description | Selected |
|--------|-------------|----------|
| 线性比例 | 物理最准确，比例关系直观。假设最大力值合理，不会太短看不见。 | |
| 对数比例（log10） | 压缩大范围数值，让小力也能看见。但比例关系不直观。 | ✓ |
| 你决定 | Claude 自行判断。 | |

**User's choice:** 对数比例（log10）
**Notes:** F=10N → 箭头长2米；F=1N → 箭头长1米。大小差10倍，视觉只差2倍。
