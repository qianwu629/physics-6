## 手动验证检查项

### 1. 轨迹残影显示
**验证步骤:**
1. 启动应用 (`npm run dev`)
2. 通过 Toolbox 添加一个球体（默认 spawn 在 (0, 5, 0)）
3. 点击 "播放" 按钮开始仿真
4. 观察球体下落并弹跳

**预期结果:** 球体后拖尾一条可见的轨迹残影线条，描绘出完整运动路径。轨迹线条随时间逐渐消失（约 10 秒内淡出）。最多显示 600 个采样点。

**状态:** ✅ 通过

### 2. 轨迹全局与按实体独立开关
**验证步骤:**
1. 添加 2 个球体（不同颜色），启动仿真
2. 点击 Toolbar 中 "轨迹" 按钮 → 所有轨迹线消失
3. 再次点击 "轨迹" 按钮 → 所有轨迹线恢复
4. 选中某个实体，在 PropertyPanel 中关闭 "显示轨迹" Switch
5. 观察该实体轨迹线消失，另一实体轨迹仍显示

**预期结果:** Toolbar 全局开关与 PropertyPanel 实体级开关相互独立。全局关闭时无轨迹；全局开启时逐个实体可按需开关。

**状态:** ✅ 通过

### 3. 速度矢量箭头
**验证步骤:**
1. 添加球体 + 初速度 (5, 8, 0)
2. 在 Toolbar 中开启 "速度" toggle（蓝色 V 图标）
3. 观察球体运动

**预期结果:** 球体中心发出蓝色箭头，箭头方向指向瞬时速度方向。箭头长度随速率变化：高速时箭头长，近静止时箭头短。箭头长度与速度大小成正比。

**状态:** ✅ 通过

### 4. 受力矢量多色显示
**验证步骤:**
1. 添加自由落体球体（无初速度）
2. 在 Toolbar 中开启 "受力" toggle
3. 观察自由落体期间 → 灰色向下箭头（重力）
4. 球体撞击地面瞬间 → 红色箭头（接触力）
5. 添加弹簧连接两个球体，开启仿真观察 → 绿色箭头（弹力）

**预期结果:**
- 灰色箭头 = 重力（始终向下）
- 绿色箭头 = 弹力（弹簧伸缩方向）
- 红色箭头 = 接触力（碰撞瞬间的法向力）
- 各色箭头独立显示，互不覆盖

**状态:** ✅ 通过

### 5. 速度和受力独立切换
**验证步骤:**
1. 开启 "速度" toggle → 仅显示蓝色速度箭头
2. 关闭 "速度" → 开启 "受力" → 仅显示彩色受力箭头
3. 同时开启两者 → 同时显示速度箭头和受力箭头（不互相干扰）
4. 同时关闭两者 → 无可视化叠加层

**预期结果:** 两个 toggle 完全独立工作，使用独立的 React 组件层（TrajectoryRenderer / VectorRenderer 各自响应 store 状态）。

**状态:** ✅ 通过

## 已知限制

- 接触力为估算值，非精确碰撞力（基于碰撞前后动量变化估算）
- 空气阻力为简化模型（F = -kv），不考虑物体形状和横截面积
- 轨迹最大保存 600 点 / 10 秒窗口，超出部分自动丢弃
