# Plan 07-05: EntityRenderer EnvironmentSync 提取

## Objective
消除 EnvironmentPanel slider 拖拽时触发所有 EntityRenderer 的 `useEffect` 同时重同步的性能问题，通过 store 中维护 `environmentSnapshot` 和提取 `EnvironmentSync` 组件实现单点同步。

## Context
`EntityRenderer.tsx` 第 57-86 行：`useEffect` 依赖 `[entity.id, rigidBody?.mass, rigidBody?.restitution, rigidBody?.friction, restitutionScale, frictionScale, drag]`。当用户拖拽 EnvironmentPanel 的 friction slider 时，`frictionScale` 变化，所有 EntityRenderer 实例（20+ 个）的 `useEffect` 同时触发，每个都调用 `setRestitution`/`setFriction`/`setLinearDamping`/`setAngularDamping`，造成主线程卡顿。

`ARCHITECTURE.md` 已建议提取 `EnvironmentSync` 组件进行集中同步。

<action>
创建 `frontend/src/components/EnvironmentSync.tsx`：
1. 这是一个纯逻辑组件（返回 null），在 `Scene3D.tsx` 中放在 `RigidBodyRefContext.Provider` 内部
2. 单点订阅环境参数变化：
   ```typescript
   const { frictionScale, restitutionScale, drag } = useSimulationStore(s => s.environment);
   const entities = useSimulationStore(s => s.entities);
   const { getRef } = useRigidBodyRefRegistry();
   ```
3. `useEffect` 依赖 `[frictionScale, restitutionScale, drag, entities]`，变化时遍历所有 dynamic 实体：
   ```typescript
   useEffect(() => {
     for (const [entityId, entity] of entities) {
       const rb = entity.components.get('rigidBody') as RigidBodyComponent | undefined;
       if (!rb || rb.kind !== 'dynamic') continue;
       const bodyRef = getRef(entityId);
       const body = bodyRef?.current;
       if (!body) continue;

       body.setAdditionalMass(rb.mass, true);
       body.setLinearDamping(drag);
       body.setAngularDamping(drag * 0.5);

       if (typeof body.numColliders === 'function' && body.numColliders() > 0) {
         const col = body.collider(0);
         col.setRestitution(Math.min(rb.restitution * restitutionScale, 1.0));
         col.setFriction(Math.min(rb.friction * frictionScale, 2.0));
       }
     }
   }, [frictionScale, restitutionScale, drag, entities, getRef]);
   ```
4. 注意：`getRef` 来自 RigidBodyRefContext，需要在 Provider 内部使用
</action>
