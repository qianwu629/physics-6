# Plan 07-02: ForceField position 双源修复

## Objective
消除 ForceField 实体中 `position` 同时存在于 `transform` 组件和 `forceField` 组件的双数据源问题，统一为单一数据源（`transform.position`）。

## Context
`BaseForceFieldComponent` 定义了 `position: [number, number, number]`（`frontend/src/ecs/types.ts` 第 92 行）。同时每个力场实体也有 `transform` 组件（含 position）。PropertyPanel 同时更新两者，但某些代码路径（场景导入、预设加载）可能只更新其中一个，导致力场可视化位置和物理计算位置不一致。

`forceFieldCalc.ts` 中 `computeNonMagneticForce` 和 `computeTotalMagneticField` 从 `forceField.position` 读取位置。`ForceFieldSystem.tsx` 第 122 行也读取 `f.position`。`ForceFieldRenderer` 和 `ForceFieldLines` 可能从 `transform.position` 读取。
